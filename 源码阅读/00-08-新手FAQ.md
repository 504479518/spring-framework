# 新手 FAQ

## 1. 我应该从哪个文件开始？

从这里开始：

- [新手调试入门](./00-02-新手调试入门.md)

## 2. BeanDefinition 是 Bean 吗？

不是。

`BeanDefinition` 是 Bean 的描述信息，类似“图纸”。Bean 实例是根据这份图纸创建出来的对象。

## 3. 为什么断点命中很多次？

Spring 启动时会创建大量基础设施 Bean 和业务 Bean，所以 `getBean()`、`doCreateBean()` 会命中很多次。

解决方式：

- 调试单个测试类。
- 设置条件断点，例如 `"myService".equals(beanName)`。
- 先看 Call Stack，不要每次都 Step Into。

## 4. 为什么我进不了 Spring 源码？

常见原因：

- IDEA 项目没有按 Gradle 导入。
- Project SDK 或 Gradle JVM 不对。
- 测试运行方式不是 Gradle。
- 源码索引还没完成。

建议先执行：

```bash
./gradlew :spring-oxm:compileTestJava
```

## 5. 为什么 `@Autowired` 不是在构造器后马上执行？

构造器注入发生在实例化阶段。

字段和方法注入通常发生在属性填充阶段，也就是：

```text
doCreateBean()
  -> populateBean()
  -> AutowiredAnnotationBeanPostProcessor.postProcessProperties()
```

## 6. `BeanFactoryPostProcessor` 和 `BeanPostProcessor` 有什么区别？

`BeanFactoryPostProcessor` 处理 BeanDefinition，发生在 Bean 实例创建之前。

`BeanPostProcessor` 处理 Bean 实例，发生在 Bean 创建和初始化过程中。

## 7. 为什么 AOP 代理后类型变了？

因为 Spring 可能返回代理对象，而不是原始对象。

- 有接口时通常使用 JDK 动态代理。
- 没有接口或强制 class 代理时使用 CGLIB。

## 8. 为什么事务 this 调用不生效？

声明式事务基于代理。`this.xxx()` 是对象内部调用，不会经过代理对象，所以不会进入 `TransactionInterceptor`。

## 9. 我应该读测试还是读源码？

两者都要。

建议方式：

```text
测试类作为入口 -> 断点进入源码 -> 观察变量 -> 回到文档记录链路
```

## 10. 一天看不完怎么办？

正常。Spring 源码不适合按页数推进，应该按链路推进。

一天只要走通一条短链路就可以，例如：

```text
refresh() -> invokeBeanFactoryPostProcessors()
```
