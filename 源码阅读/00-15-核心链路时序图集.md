# Spring 核心链路时序图集

> 用 Mermaid 时序图直观展示 Spring 各核心模块的方法调用链路。
> 建议在 IDE 或 Markdown 预览器中查看，断点调试时对照阅读。

---

## 一、IoC 容器启动（refresh）

```mermaid
sequenceDiagram
    participant App as 应用代码
    participant Ctx as AnnotationConfigApplicationContext
    participant AAC as AbstractApplicationContext
    participant BF as DefaultListableBeanFactory
    participant BPP as BeanPostProcessor 们

    App->>Ctx: new AnnotationConfigApplicationContext(Config.class)
    Ctx->>Ctx: register(Config.class) 注册配置类
    Ctx->>AAC: refresh()
    
    Note over AAC: ① prepareRefresh() 准备环境
    AAC->>AAC: prepareRefresh()
    
    Note over AAC: ② obtainFreshBeanFactory() 获取 BeanFactory
    AAC->>BF: 返回已创建的 DefaultListableBeanFactory
    
    Note over AAC: ③ prepareBeanFactory() 注册基础设施
    AAC->>BF: 注册 ClassLoader、SpEL 解析器、Aware 处理器
    
    Note over AAC: ④ invokeBeanFactoryPostProcessors()
    AAC->>BF: 执行 ConfigurationClassPostProcessor
    Note right of BF: 解析 @ComponentScan、@Bean、@Import<br/>注册所有 BeanDefinition
    
    Note over AAC: ⑤ registerBeanPostProcessors()
    AAC->>BF: 注册 AutowiredAnnotationBeanPostProcessor 等
    
    Note over AAC: ⑥ finishBeanFactoryInitialization()
    AAC->>BF: preInstantiateSingletons()
    loop 遍历所有非懒加载单例 BeanDefinition
        BF->>BF: getBean(beanName) → doGetBean() → createBean()
    end
    
    Note over AAC: ⑦ finishRefresh()
    AAC->>AAC: 发布 ContextRefreshedEvent
```

## 二、Bean 创建全链路（getBean → doCreateBean）

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant ABF as AbstractBeanFactory
    participant DSR as DefaultSingletonBeanRegistry
    participant AACBF as AbstractAutowireCapableBeanFactory
    participant BPP as BeanPostProcessor 们

    Caller->>ABF: getBean("userService")
    ABF->>ABF: doGetBean("userService")
    
    Note over ABF: 第 1 步：查缓存
    ABF->>DSR: getSingleton("userService")
    DSR-->>ABF: null（首次创建）
    
    Note over ABF: 第 2 步：处理 depends-on
    ABF->>ABF: 检查并创建依赖的 Bean
    
    Note over ABF: 第 3 步：创建单例
    ABF->>DSR: getSingleton("userService", ObjectFactory)
    DSR->>DSR: beforeSingletonCreation() 标记"正在创建"
    DSR->>AACBF: createBean("userService", mbd, args)
    
    Note over AACBF: ── doCreateBean 三阶段 ──
    
    Note over AACBF: 阶段 1：实例化
    AACBF->>AACBF: createBeanInstance() 反射调用构造器
    
    Note over AACBF: 提前暴露到三级缓存
    AACBF->>DSR: addSingletonFactory("userService", ObjectFactory)
    
    Note over AACBF: 阶段 2：属性填充
    AACBF->>AACBF: populateBean()
    AACBF->>BPP: AutowiredAnnotationBeanPostProcessor 注入依赖
    
    Note over AACBF: 阶段 3：初始化
    AACBF->>AACBF: initializeBean()
    AACBF->>BPP: invokeAwareMethods()（BeanNameAware 等）
    AACBF->>BPP: postProcessBeforeInitialization()
    AACBF->>AACBF: invokeInitMethods()（@PostConstruct / InitializingBean）
    AACBF->>BPP: postProcessAfterInitialization()
    Note right of BPP: AOP 代理在这里创建！<br/>AbstractAutoProxyCreator.wrapIfNecessary()
    
    AACBF-->>DSR: 返回 Bean（可能是代理对象）
    DSR->>DSR: addSingleton() 放入一级缓存
    DSR->>DSR: afterSingletonCreation() 移除"正在创建"标记
    DSR-->>ABF: 返回单例
    ABF-->>Caller: 返回 Bean 实例
```

## 三、循环依赖解决（三级缓存）

```mermaid
sequenceDiagram
    participant BF as BeanFactory
    participant DSR as DefaultSingletonBeanRegistry
    participant A as Bean A 创建流程
    participant B as Bean B 创建流程

    BF->>A: getBean("A") → createBean("A")
    A->>A: ① createBeanInstance() 实例化 A（原始对象）
    A->>DSR: ② addSingletonFactory("A", () → getEarlyBeanReference(A))
    Note right of DSR: 三级缓存放入 ObjectFactory
    
    A->>A: ③ populateBean() 填充属性
    Note over A: 发现需要注入 B
    A->>BF: getBean("B")
    
    BF->>B: createBean("B")
    B->>B: ① createBeanInstance() 实例化 B
    B->>DSR: ② addSingletonFactory("B", ...)
    
    B->>B: ③ populateBean() 填充属性
    Note over B: 发现需要注入 A
    B->>BF: getBean("A")
    
    BF->>DSR: getSingleton("A", true)
    Note over DSR: 一级缓存：miss<br/>发现 A 正在创建中<br/>二级缓存：miss<br/>三级缓存：hit！调用 ObjectFactory
    DSR->>DSR: ObjectFactory.getObject() → getEarlyBeanReference(A)
    Note right of DSR: 如果 A 需要 AOP 代理，<br/>这里提前创建代理对象
    DSR->>DSR: 结果放入二级缓存，删除三级缓存
    DSR-->>B: 返回 A 的早期引用（可能是代理）
    
    B->>B: 完成属性注入（A 已注入）
    B->>B: ④ initializeBean() 初始化 B
    B-->>BF: B 创建完成 → 放入一级缓存
    
    BF-->>A: 返回 B 的完整实例
    A->>A: 完成属性注入（B 已注入）
    A->>A: ④ initializeBean() 初始化 A
    Note over A: AOP 代理已在早期引用时创建，<br/>postProcessAfterInitialization 会跳过
    A-->>BF: A 创建完成 → 放入一级缓存
```

## 四、AOP 代理执行（拦截器链）

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant Proxy as AOP 代理对象
    participant RMI as ReflectiveMethodInvocation
    participant Around as @Around 拦截器
    participant Before as @Before 拦截器
    participant Target as 目标方法
    participant After as @AfterReturning 拦截器

    Caller->>Proxy: proxy.doSomething()
    Proxy->>RMI: new ReflectiveMethodInvocation(拦截器链)
    RMI->>RMI: proceed() [index: -1 → 0]
    
    RMI->>Around: invoke(invocation)
    Note over Around: 前置逻辑执行
    Around->>RMI: invocation.proceed() [index: 0 → 1]
    
    RMI->>Before: invoke(invocation)
    Note over Before: @Before 方法执行
    Before->>RMI: invocation.proceed() [index: 1 → 2]
    
    Note over RMI: index == 拦截器数 - 1<br/>所有拦截器执行完毕
    RMI->>Target: invokeJoinpoint() 反射调用目标方法
    Target-->>RMI: 返回结果
    
    RMI-->>Before: 返回结果
    Before-->>RMI: 返回结果 [index: 2 → 1]
    
    Note over After: @AfterReturning 方法执行
    
    RMI-->>Around: 返回结果
    Note over Around: 后置逻辑执行
    Around-->>RMI: 返回最终结果
    
    RMI-->>Proxy: 返回结果
    Proxy-->>Caller: 返回结果
```

## 五、@Transactional 事务执行

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant Proxy as 事务代理
    participant TI as TransactionInterceptor
    participant TAS as TransactionAspectSupport
    participant PTM as AbstractPlatformTransactionManager
    participant DS as DataSource / Connection

    Caller->>Proxy: proxy.placeOrder()
    Proxy->>TI: invoke(MethodInvocation)
    TI->>TAS: invokeWithinTransaction()
    
    Note over TAS: ① 解析 @Transactional 属性
    TAS->>TAS: getTransactionAttributeSource().getTransactionAttribute()
    Note right of TAS: propagation=REQUIRED<br/>isolation=DEFAULT<br/>rollbackFor=Exception.class
    
    Note over TAS: ② 确定事务管理器
    TAS->>TAS: determineTransactionManager()
    
    Note over TAS: ③ 创建事务
    TAS->>PTM: getTransaction(txAttr)
    PTM->>PTM: doGetTransaction() 检查 ThreadLocal
    
    alt 当前无事务 + REQUIRED
        PTM->>DS: 获取数据库连接
        PTM->>DS: connection.setAutoCommit(false)
        PTM->>PTM: 绑定连接到 ThreadLocal
    else 当前有事务 + REQUIRED
        PTM->>PTM: 加入已有事务（不新建）
    else 当前有事务 + REQUIRES_NEW
        PTM->>PTM: suspend() 挂起当前事务
        PTM->>DS: 获取新连接，开启新事务
    end
    
    TAS-->>TAS: 返回 TransactionStatus
    
    Note over TAS: ④ 执行目标方法
    TAS->>Caller: invocation.proceedWithInvocation()
    Note over Caller: 业务代码执行<br/>SQL 操作使用 ThreadLocal 中的连接
    Caller-->>TAS: 返回结果 / 抛出异常
    
    alt 正常返回
        Note over TAS: ⑤ 提交事务
        TAS->>PTM: commit(status)
        PTM->>DS: connection.commit()
    else 抛出异常
        Note over TAS: ⑤ 异常处理
        TAS->>TAS: completeTransactionAfterThrowing()
        alt RuntimeException / Error（默认回滚）
            TAS->>PTM: rollback(status)
            PTM->>DS: connection.rollback()
        else 受检异常（默认提交！）
            TAS->>PTM: commit(status)
            Note right of PTM: 常见坑！需配置 rollbackFor
        end
    end
    
    Note over TAS: ⑥ 清理
    TAS->>TAS: cleanupTransactionInfo() 恢复 ThreadLocal
```

## 六、Spring MVC 请求处理

```mermaid
sequenceDiagram
    participant Client as HTTP 客户端
    participant Tomcat as Servlet 容器
    participant DS as DispatcherServlet
    participant HM as HandlerMapping
    participant HA as HandlerAdapter
    participant HI as HandlerInterceptor 们
    participant Ctrl as Controller 方法
    participant MConv as HttpMessageConverter

    Client->>Tomcat: HTTP 请求 POST /api/order
    Tomcat->>DS: doService() → doDispatch()
    
    Note over DS: ① 检查 multipart
    DS->>DS: checkMultipart()
    
    Note over DS: ② 查找 Handler
    DS->>HM: getHandler(request)
    HM->>HM: 遍历 HandlerMapping
    Note right of HM: RequestMappingHandlerMapping<br/>匹配 @RequestMapping 注解
    HM-->>DS: HandlerExecutionChain（Controller + 拦截器链）
    
    Note over DS: ③ 查找 Adapter
    DS->>HA: getHandlerAdapter(handler)
    Note right of HA: RequestMappingHandlerAdapter
    
    Note over DS: ④ 执行拦截器前置
    DS->>HI: applyPreHandle()
    loop 每个 HandlerInterceptor
        HI->>HI: preHandle()
    end
    
    Note over DS: ⑤ 调用 Controller
    DS->>HA: handle(request, response, handler)
    HA->>HA: 参数解析
    Note right of HA: @RequestBody → Jackson 反序列化<br/>@PathVariable → URL 路径提取<br/>@RequestParam → 查询参数
    HA->>Ctrl: 反射调用 Controller 方法
    Ctrl-->>HA: 返回结果对象
    
    alt @ResponseBody
        HA->>MConv: 序列化为 JSON（Jackson）
        MConv->>Tomcat: 写入 response body
        HA-->>DS: ModelAndView = null
    else 返回视图名
        HA-->>DS: ModelAndView("order_success", model)
    end
    
    Note over DS: ⑥ 执行拦截器后置
    DS->>HI: applyPostHandle()
    
    Note over DS: ⑦ 处理结果
    DS->>DS: processDispatchResult()
    alt ModelAndView 不为 null
        DS->>DS: render() 渲染视图
    end
    DS->>HI: triggerAfterCompletion()
    
    DS-->>Tomcat: 响应完成
    Tomcat-->>Client: HTTP 响应 200 OK
```

## 七、@Autowired 依赖注入

```mermaid
sequenceDiagram
    participant AACBF as AbstractAutowireCapableBeanFactory
    participant AABPP as AutowiredAnnotationBeanPostProcessor
    participant BF as DefaultListableBeanFactory
    participant Target as 目标 Bean

    AACBF->>AACBF: populateBean()
    AACBF->>AABPP: postProcessProperties(pvs, bean, beanName)
    
    AABPP->>AABPP: findAutowiringMetadata(beanClass)
    Note right of AABPP: 反射扫描类的字段和方法<br/>找到所有 @Autowired / @Value 注解
    
    AABPP->>AABPP: metadata.inject(bean, beanName, pvs)
    
    loop 每个 @Autowired 字段
        AABPP->>BF: resolveDependency(descriptor, beanName)
        
        alt 按类型查找
            BF->>BF: findAutowireCandidates(requiredType)
            Note right of BF: 从所有 BeanDefinition 中<br/>找到类型匹配的候选 Bean
        end
        
        alt 多个候选
            BF->>BF: 按 @Primary → @Priority → beanName 筛选
        end
        
        BF->>BF: getBean(候选 beanName) 获取/创建依赖
        BF-->>AABPP: 返回依赖实例
        
        AABPP->>Target: field.set(bean, 依赖实例) 反射注入
    end
    
    AABPP-->>AACBF: 注入完成
```

## 使用建议

1. **断点调试时对照**：在 IDE 中打开对应源码，时序图作为「地图」，知道当前在链路的哪个位置
2. **面试复述**：用时序图的步骤编号来组织回答，例如「@Transactional 的执行分为 6 步...」
3. **画自己的图**：遇到新场景时，模仿这些图的格式画自己的时序图
