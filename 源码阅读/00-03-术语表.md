# Spring 源码阅读术语表

这份术语表面向第一次阅读 Spring 源码的学习者。先理解这些词，再进入源码会顺很多。

## IoC / DI

IoC 是控制反转，意思是对象的创建和依赖关系不再由业务代码手动控制，而是交给容器控制。

DI 是依赖注入，是 IoC 的实现方式。Spring 通过构造器、字段、方法等方式把依赖对象注入进来。

## Bean

Bean 是由 Spring 容器管理的对象。普通 Java 对象被注册到容器之后，就成为 Spring 管理的 Bean。

## BeanDefinition

BeanDefinition 是 Bean 的“元数据”，不是 Bean 实例。

它描述：

- Bean 的类名
- 作用域
- 是否懒加载
- 构造参数
- 属性值
- 初始化方法
- 销毁方法

源码入口：

- [BeanDefinition.java](../spring-beans/src/main/java/org/springframework/beans/factory/config/BeanDefinition.java)

## BeanFactory

BeanFactory 是 Spring 最核心的容器接口，负责保存 BeanDefinition、创建 Bean、获取 Bean。

源码入口：

- [BeanFactory.java](../spring-beans/src/main/java/org/springframework/beans/factory/BeanFactory.java)
- [DefaultListableBeanFactory.java](../spring-beans/src/main/java/org/springframework/beans/factory/support/DefaultListableBeanFactory.java)

## ApplicationContext

ApplicationContext 是 BeanFactory 的增强版，除了 IoC 容器能力，还提供事件、资源加载、国际化等能力。

源码入口：

- [ApplicationContext.java](../spring-context/src/main/java/org/springframework/context/ApplicationContext.java)
- [AbstractApplicationContext.java](../spring-context/src/main/java/org/springframework/context/support/AbstractApplicationContext.java)

## refresh()

`refresh()` 是 Spring 容器启动的主流程。读 Spring 源码应优先读它。

源码入口：

- [AbstractApplicationContext.java](../spring-context/src/main/java/org/springframework/context/support/AbstractApplicationContext.java)

## BeanFactoryPostProcessor

BeanFactoryPostProcessor 在 Bean 实例创建前执行，主要用于修改 BeanDefinition。

典型例子：

- `ConfigurationClassPostProcessor`

源码入口：

- [BeanFactoryPostProcessor.java](../spring-beans/src/main/java/org/springframework/beans/factory/config/BeanFactoryPostProcessor.java)
- [ConfigurationClassPostProcessor.java](../spring-context/src/main/java/org/springframework/context/annotation/ConfigurationClassPostProcessor.java)

## BeanPostProcessor

BeanPostProcessor 在 Bean 实例创建后、初始化前后执行，用于增强或替换 Bean 实例。

AOP 代理创建就和 BeanPostProcessor 有关。

源码入口：

- [BeanPostProcessor.java](../spring-beans/src/main/java/org/springframework/beans/factory/config/BeanPostProcessor.java)

## FactoryBean

FactoryBean 是一种特殊 Bean。普通 Bean 直接代表对象本身；FactoryBean 代表一个“生产对象的工厂”。

`getBean("xxx")` 默认拿到的是 `FactoryBean.getObject()` 的产物。

`getBean("&xxx")` 才是拿到 FactoryBean 本身。

源码入口：

- [FactoryBean.java](../spring-beans/src/main/java/org/springframework/beans/factory/FactoryBean.java)

## AOP

AOP 是面向切面编程。Spring AOP 通过代理对象在方法调用前后插入额外逻辑。

源码入口：

- [AbstractAutoProxyCreator.java](../spring-aop/src/main/java/org/springframework/aop/framework/autoproxy/AbstractAutoProxyCreator.java)
- [JdkDynamicAopProxy.java](../spring-aop/src/main/java/org/springframework/aop/framework/JdkDynamicAopProxy.java)
- [CglibAopProxy.java](../spring-aop/src/main/java/org/springframework/aop/framework/CglibAopProxy.java)

## Advisor / Advice / Pointcut

Pointcut 定义哪些方法需要增强。

Advice 定义增强逻辑。

Advisor 是 Pointcut 和 Advice 的组合。

## TransactionInterceptor

事务拦截器。`@Transactional` 方法被代理后，调用时会进入这个拦截器。

源码入口：

- [TransactionInterceptor.java](../spring-tx/src/main/java/org/springframework/transaction/interceptor/TransactionInterceptor.java)

## DispatcherServlet

Spring MVC 的前端控制器，所有 MVC 请求最终进入它。

源码入口：

- [DispatcherServlet.java](../spring-webmvc/src/main/java/org/springframework/web/servlet/DispatcherServlet.java)

## HandlerMapping / HandlerAdapter

HandlerMapping 负责找到请求对应的处理器。

HandlerAdapter 负责调用这个处理器。

源码入口：

- [HandlerMapping.java](../spring-webmvc/src/main/java/org/springframework/web/servlet/HandlerMapping.java)
- [HandlerAdapter.java](../spring-webmvc/src/main/java/org/springframework/web/servlet/HandlerAdapter.java)
