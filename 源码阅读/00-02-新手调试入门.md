# 新手调试入门

这份文档只解决一个问题：第一次怎么在 IDEA 里跑起来并命中 Spring 源码断点。

## 1. 确认 IDEA 配置

打开项目：

```text
/Users/hefei/github/java/spring-framework
```

IDEA 设置建议：

```text
Project SDK: JDK 17
Gradle JVM: JDK 17
Run tests using: Gradle
```

如果 IDEA 识别异常，先在终端执行：

```bash
./gradlew :spring-oxm:compileTestJava
```

## 2. 第一个断点

先不要写自己的 demo，直接跑 Spring 自带测试。

打开源码：

- [AbstractApplicationContext.java](../spring-context/src/main/java/org/springframework/context/support/AbstractApplicationContext.java)

在这个方法第一行打断点：

```java
refresh()
```

## 3. 跑第一个测试

打开测试：

- [AnnotationConfigApplicationContextTests.java](../spring-context/src/test/java/org/springframework/context/annotation/AnnotationConfigApplicationContextTests.java)

在 IDEA 里运行单个测试类，或使用命令：

```bash
./gradlew :spring-context:test --tests "*AnnotationConfigApplicationContextTests"
```

如果断点命中，说明你已经进入 Spring 容器启动主线。

## 4. 第一次单步调试路线

第一次不要钻进所有方法，只跟这条路线：

```text
AnnotationConfigApplicationContext 构造器
  -> register(...)
  -> refresh()
  -> invokeBeanFactoryPostProcessors(...)
  -> registerBeanPostProcessors(...)
  -> finishBeanFactoryInitialization(...)
  -> preInstantiateSingletons()
```

重点观察：

- `beanFactory` 是什么类型？
- 当前有多少个 `BeanDefinition`？
- `ConfigurationClassPostProcessor` 什么时候执行？
- 普通 Bean 是什么时候开始创建的？

## 5. 第二个断点：Bean 创建

打开源码：

- [AbstractBeanFactory.java](../spring-beans/src/main/java/org/springframework/beans/factory/support/AbstractBeanFactory.java)
- [AbstractAutowireCapableBeanFactory.java](../spring-beans/src/main/java/org/springframework/beans/factory/support/AbstractAutowireCapableBeanFactory.java)

建议断点：

```java
AbstractBeanFactory.doGetBean(...)
AbstractAutowireCapableBeanFactory.doCreateBean(...)
```

如果断点命中次数太多，可以加条件断点：

```java
"testBean".equals(beanName)
```

不确定 Bean 名称时，先不加条件，命中后观察变量窗口里的 `beanName`。

## 6. 第三个断点：依赖注入

打开源码：

- [AutowiredAnnotationBeanPostProcessor.java](../spring-beans/src/main/java/org/springframework/beans/factory/annotation/AutowiredAnnotationBeanPostProcessor.java)
- [DefaultListableBeanFactory.java](../spring-beans/src/main/java/org/springframework/beans/factory/support/DefaultListableBeanFactory.java)

建议断点：

```java
AutowiredAnnotationBeanPostProcessor.postProcessProperties(...)
DefaultListableBeanFactory.doResolveDependency(...)
```

重点观察：

- 当前被注入的字段或方法是什么？
- 依赖类型是什么？
- 候选 Bean 有几个？
- 最终选中了哪个 Bean？

## 7. 新手不要做的事

- 不要一开始跑全量 `./gradlew test`。
- 不要一开始读 `DispatcherServlet`。
- 不要看到每个方法都 Step Into。
- 不要先背设计模式，再看源码。
- 不要只看静态类图，必须跑断点。

## 8. 第一天验收

完成这几个动作就算入门成功：

- [ ] 能在 `refresh()` 命中断点。
- [ ] 能找到当前 `beanFactory`。
- [ ] 能看到 BeanDefinition 数量。
- [ ] 能进入 `preInstantiateSingletons()`。
- [ ] 能进入 `doGetBean()`。
- [ ] 能说明 BeanDefinition 不是 Bean 实例。
